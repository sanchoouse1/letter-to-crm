# Письмо → карточка CRM

Менеджеры вручную переносят данные из писем клиентов в CRM и ошибаются. Инструмент берёт текст входящего письма и возвращает структурированную карточку: компания, контакт, суть запроса, продукт, срочность. Для каждого поля приводится цитата из письма, чтобы менеджер проверял карточку, а не перепечатывал её.

LLM — GigaChat через OpenAI-совместимый API.

## Что где

| Пункт задания | Где |
|---|---|

| Промпты | [`prompts/extract_card.md`](prompts/extract_card.md) — боевой промпт; [`docs/PROMPTS.md`](docs/PROMPTS.md) — почему он такой и как менялся v1 → v2 |
| Записка | [`docs/NOTE.md`](docs/NOTE.md) |
| Результаты прогонов | [`docs/eval/`](docs/eval/) — отчёты и полные ответы модели |

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать GIGACHAT_AUTH_KEY и путь к сертификату

uvicorn app.main:app --reload   # UI: http://localhost:8000
python eval.py                  # проверка качества на примерах из data/
```

## Структура

```
app/            FastAPI-приложение, клиент GigaChat, экстрактор
prompts/        промпты
data/           синтетические письма, эталоны, справочник продуктов
eval.py         прогон по примерам и отчёт о качестве
docs/           задачи, промпты, записка, скриншоты
```
