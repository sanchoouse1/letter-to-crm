## Критерий «готово»

- На всех примерах ключевые поля (компания, email, телефон, срочность, продукт из справочника) совпадают с эталоном.
- Для каждого заполненного поля модель приводит цитату, и эта цитата действительно есть в письме.
- Ответ — валидный JSON, приходит за ~10 с, стоимость письма считается по токенам.
